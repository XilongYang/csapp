# rtarget-dumped-code.s 指令分类清单

数据来源：`rtarget-dumped-code.s`（objdump 反汇编格式）。
取每条指令的助记符去重、分类，括号内为出现次数。

## 数据传送类

| 助记符 | 次数 | 说明 |
|---|---|---|
| lea | 2262 | 加载有效地址 |
| mov | 2067 | 传送数据 |
| movl | 2003 | 传送 32 位立即数/数据（MOV 的宽度标注形式） |
| xchg | 47 | 交换 |
| pop | 9 | 出栈 |
| push | 3 | 入栈 |
| movsxd | 2 | 符号扩展传送（32→64 位） |

## 汇总

- 字面 token 共 **33 种**。
- 剔除 3 个反汇编产物（`(bad)`、`rex.W`、`rex.B`）后，真实机器指令 **30 种**。
- 备注：`mov` 与 `movl` 本质同属 MOV 族，此处按宽度标注分开列出；若合并计为一类，真实指令种类为 **29 种**。
